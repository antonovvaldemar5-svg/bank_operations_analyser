# Анализ банковских транзакций

Приложение для анализа банковских операций из Excel.

## Что умеет:
1. **Главная страница** - показывает расходы по картам, топ операций, курсы валют
2. **Инвесткопилка** - копит деньги через округление покупок
3. **Поиск** - ищет операции по названию
4. **Отчеты** - строит отчеты по категориям и дням недели

## Как запустить:
```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить
python -m src.main

# Запустить тесты
pytest tests/
Структура:
text
src/           - исходный код
tests/         - тесты
data/          - файлы с данными
reports/       - генерируемые отчеты
Требования:
Python 3.8+

Покрытие тестами: >80%

Все тесты проходят

Настройки:
Файл user_settings.json позволяет настроить:

Отслеживаемые валюты

Отслеживаемые акции

Лимит округления для инвесткопилки
